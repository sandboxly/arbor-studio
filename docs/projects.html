Projects and undo

A project file stores everything needed to grow a tree again: the generators with their settings and curves, materials, forces, pruning, collision settings, node edits and the tree settings. Project files end in .arbor.json.

Saving and opening

CommandmacOSWindows and Linux
File › New Tree⌘N
File › Open…⌘OCtrl+O
File › Save⌘SCtrl+S
File › Save As…⇧⌘S

New Tree starts from the Sapling preset. Save writes to the current file; for a tree that has not been saved yet it asks for a file name, like Save As. The toolbar has New, Open and Save buttons for the same commands.

The window title shows the file name, a dot (•) when there are changes since the tree was opened or saved, and the tree's name.

To open a project when ArborStudio starts, pass the file on the command line: arbor_studio oak.arbor.json.

Open Recent

File › Open Recent lists the last ten projects you opened or saved, newest first. Each entry shows the file name and, in grey, the folder it is in. Your home folder is shortened to ~ on macOS and Linux.

  • Entries whose file no longer exists are disabled and marked as missing. Remove Missing removes them from the list.
  • Clear Menu (Clear list on Windows and Linux) empties the list.

Projects that agents open or save appear in the list as well.

Undo and redo

Every change can be undone, including changes made by a coding agent, preset loads and node edits. A drag on a slider counts as one step, recorded when you release the mouse button. ArborStudio keeps the last 200 steps.

CommandmacOSWindows and Linux
Undo⌘ZCtrl+Z
Redo⇧⌘ZCtrl+Shift+Z

The Undo and Redo buttons in the toolbar do the same. The history is not saved with the project.

The project file

Project files are JSON text. They can be kept in version control, compared between versions and generated by scripts. Paths to textures and leaf models are stored as absolute paths; when you move a project to another computer, choose the images again in the material editor.

When a file contains values outside the allowed ranges, ArborStudio limits them to the nearest allowed value on opening.
