Installing and starting

ArborStudio is a single program with no installer and no runtime dependencies. Download the archive for your system, unpack it and start the program.

System requirements

  • macOS 11 or later (Apple silicon or Intel), Windows 10 or later (64-bit), or a 64-bit Linux desktop with X11 or Wayland.
  • A graphics card with OpenGL 3.3 support. Without it, the viewport falls back to a slower software path.
  • About 30 MB of disk space, plus space for your projects and exports.

Downloading

Every release on the project's GitHub Releases page has one download per system:

SystemFileContents
macOSArborStudio-macos-universal.zipThe app ArborStudio.app, for Apple silicon and Intel Macs.
Windowsarbor_studio-windows-x86_64.ziparbor_studio.exe and the licence.
Linuxarbor_studio-linux-x86_64.tar.gzThe arbor_studio program and the licence.

macOS

  1. Unpack the zip file and move ArborStudio.app to your Applications folder.
  2. Double-click the app. Releases signed and notarised by the developer open straight away.
  3. If macOS reports that it cannot check the app for malicious software, open System Settings › Privacy & Security, scroll to the message about ArborStudio and click Open Anyway. You only need to do this once.

Windows

  1. Unpack the zip file to a folder of your choice, for example C:\Tools\ArborStudio.
  2. Double-click arbor_studio.exe. If Windows SmartScreen shows a warning, click More info and then Run anyway.

Linux

  1. Unpack the archive: tar -xzf arbor_studio-linux-x86_64.tar.gz
  2. Start the program from a terminal with ./arbor_studio, or create a desktop launcher that points to it.

The first start

ArborStudio opens with a small sapling. The status indicator at the right end of the toolbar shows Agent link ready once the built-in MCP server is listening. If you don't use coding agents, you can ignore it; see Coding agents for details.

To open an existing project, use File › Open… or File › Open Recent, or pass the project's path on the command line when you start the program.

Command-line options

OptionEffect
project.arbor.jsonOpens the project file.
--port NUses port N for the MCP server (default 7878). The environment variable ARBOR_MCP_PORT does the same.
--no-mcpStarts without the MCP server.
--mcp-stdioRuns as a stdio MCP server for agents that start their tools themselves. It relays to an open window and starts one if needed.
--headlessRuns without a window. With --mcp-stdio it answers requests itself; otherwise it serves MCP over HTTP. Useful for build scripts and continuous integration.
--screenshot FILE.pngOpens the window, saves a picture of it and exits.
--helpLists the options.

Building from source

ArborStudio is written in Rust. To build it yourself, install Rust from rustup.rs, then run in the source folder:

cargo build --release

The program is written to target/release/arbor_studio. On Linux, install the window-system development packages first, for example on Ubuntu:

sudo apt install libgtk-3-dev libxkbcommon-dev libwayland-dev libgl1-mesa-dev

To make a Mac app from your build, run sh macos/bundle.sh target/release/arbor_studio <empty folder>.

Opening this help

Choose Help › ArborStudio Help in the menu bar or press F1. The help opens in your default web browser, so the browser's back and forward buttons, bookmarks, search within the page and printing all work as usual. Help › Keyboard and mouse opens the list of shortcuts directly.

The help is published online with the project and needs an internet connection. To read it offline, download the project's source code: the same pages are in its docs folder and open in any browser.

On each page, the contents list is on the left and the field above it filters the list. Links at the end of each page lead to the previous and next page.
