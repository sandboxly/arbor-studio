Parameter reference

This page lists every setting with its label in the Properties panel, its name for agents and in project files, the generators it applies to, its range and its effect.

The ranges are the values that project files and agents accept. Some sliders cover a smaller, commonly used part of the range. Values outside the range are set to the nearest allowed value.
